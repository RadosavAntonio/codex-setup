# Check a dependency

Inspect whether the dependency or an equivalent is already present. Use current primary registry and project sources to check version, licence, maintenance, adoption, bundle or binary size, security history, types, platform compatibility, and native linking requirements. Compare lighter alternatives and a small local implementation.

Report package, version, size, last release, usage signal, licence, types, platform impact, alternatives, and a recommendation. Do not install until the user approves the recommended dependency.
